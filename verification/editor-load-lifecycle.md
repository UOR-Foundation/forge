# FA-66 — Owned editor initialization

Authority: `FoundrySpecification.editorLoadLifecycleBoundary`, `EditorLoadPhase` and `EditorLoadError` in `app/src/FoundrySpecification.lex.tex`.

The capability, scenario and failing Rust acceptance were registered before implementation. The integrated offline editor intermittently reported an unhandled rejection. Evaluating the actual renderer projection reproduced the first defect deterministically: cancelling its first loader request rejected a detached theme-initialization promise and marked themes ready before they existed. The initializer now returns the configuration continuation itself, carries that caller's cancellation handle and records readiness only after both themes and language options are installed. Cancellation retains the imported loader discriminator. Load and configuration failures use fixed `editorLoadFailed` and `editorThemeFailed` codes without original private details.

The real-browser negative test exposed a second defect in locked `@monaco-editor/loader` 1.5.0: its success-only `then` creates a detached rejection when the script fails, even though a separate `catch` rejects the wrapped result. A project-owned build transformation replaces that pair with one `then(success, reject)` only for the exact source SHA256 of its ES or CommonJS implementation. Drift refuses with `editorLoaderProjectionMismatch`; the renderer build also refuses if no loader was projected. Installed package files remain unchanged. The original source fixture retains the upstream MIT license.

Seven focused controls evaluate the actual renderer projection and independently test locked-source refusal. The browser gate compiles that same projection with the locked compiler and loader, serves the verified Monaco assets, and exercises first-mount cancellation, concurrent/remounted callers, cached cancellation, a deliberately failing theme operation followed by recovery, and an aborted loader script. All scenarios preserve the expected dark theme, typed results and zero page exceptions/external requests.

Seven planted defects are rejected: detached theme initialization, premature readiness, removed cancellation, private load-error propagation, disabled source hash, restored detached loader continuation, and omitted build-projection guard.
