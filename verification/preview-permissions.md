# Preview permissions (FA-39)

Authority: `app/src/FoundrySpecification.lex.tex::previewPermissionBoundary`
and `PreviewPermissionError`.

Generated-code previews disclose their exact captured source and bounded HTTPS
origins before compilation. A visitor explicitly allows each build. Denial,
Escape, offline state and deadline expiry create no grant. The host installs
only the copied disclosure after source comparison. A transaction compares the
captured previous permission record and rechecks expiry, so concurrent
revocation or replacement rejects stale approval. Approval and prior records
are copied before asynchronous transaction work.

The persistent Preview permissions control lists grants after reload, revokes
serving and network access, and unloads matching local frames. The existing
worker checks grants on serving and future external requests. Revocation cannot
recall transferred data or stop already executing remote work. The dialog states
these limits and the data destinations may receive; labels use text nodes and
default focus is denial. Local network-free canonical projection retains its
existing path. This does not grant portable-build or publication effects.

The registered ID, scenario and missing-oracle Rust failure preceded
implementation. Initial Node execution failed on the missing module. All 236
combined Node controls, local Rust workspace tests, Clippy, formatting and shell
parsing pass. Seven restored mutations are rejected: duplicate destinations,
expired approval, offline admission, mutable disclosure, skipped revocation and
missing grant comparison and legacy consent bypass. The grant-comparison mutation fails actual browser acceptance.

Real Chromium runs the actual host and browser compiler. Denial stores no grant;
approval stores exactly the two disclosed origins. After reload, revocation
removes both serving and network permission and unloads the matching frame. A
stale transaction cannot reinstall the revoked grant. Offline attempts and
source changes during approval refuse. No page exceptions occur. The canonical
import/restore build regression also retains its twelve refusals. Local shell
provenance is diagnostic; full exact-head immutable SDK/Studio acceptance is
required before readiness.

The worker refuses legacy networked preview grants without source-bound consent
metadata on both serving and subsequent requests. A negative test first failed
on the missing worker boundary; valid, missing-metadata, wrong-ID and network-free
controls cover it. The extracted worker policy harness initially lacked its endpoint-regex binding; adding the actual worker constant restored the baseline before the legacy mutation was rerun. Existing previews require fresh approval to regain network
access. The boundary does not authenticate arbitrary same-origin scripts or
establish all-effect privacy and release acceptance.
